## Interpretation and limits

This is a fixture-based regression suite, not a market accuracy benchmark. Counts include repeated recommendation occurrences across runs. Structured profile validity measures persisted states, including safely retained states on parse errors; it is not natural-language extraction accuracy. The malformed-output case deliberately fails parsing and must fail closed. Numeric scoring is tested separately in tests/core.test.ts. This deterministic run does not measure live model extraction, network availability, live listing precision, transport accuracy or business time savings. Separate organiser-gateway and DeepSeek live reports are saved under evals/ and documented in docs/GATEWAY_VALIDATION_2026-09-22.md. The official HDB snapshot is historical evidence, not current listing inventory. Adversarial coverage is representative, not a proof against all prompt injections.

See evals/results.json for machine-readable results and docs/QA.md for HTTP/browser/build verification.
