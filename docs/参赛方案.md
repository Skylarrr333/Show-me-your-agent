## 如何证明价值

安排至少 2 位测试者，每人处理 5 个陌生买家 brief。对同一份模拟库存分别做人工检索和 Agent 辅助检索，交叉安排顺序，避免第二次因记忆而更快。计时从看到 brief 到得到可讨论的 Top 3，并分别计入人工审核时间。

记录：任务耗时、硬条件违规数量、需要纠正的字段、是否接受 Top 3、变化后名单是否正确失效。报告中同时给出任务数和失败例子；样本很小时只写“试用观察”。不要预先写“效率提升 80%”或把程序 fit score 当推荐准确率。

模型评测分三类：

- 回归测试：确定性规则与状态转移是否按预期工作。
- Live 小样本：真实 API 是否正确处理作者编写的英文／中文场景，不能外推自然语言总体准确率。
- 业务试用：经纪人或测试者是否真的更快、能否接受推荐，尚待执行。
