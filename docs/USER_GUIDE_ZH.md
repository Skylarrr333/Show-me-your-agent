# 网站使用指南（2026-09-26）

首页以输入需求为主。`Find a home` 找房，`Saved` 查看收藏并比较，`About` 查看数据、地图和能力边界。筛选条件和执行过程默认折叠。

## 从一句话开始

输入 `4 ROOM in Clementi under SGD 800k`，点击 **Find my home**。也可以输入中文：`在 Clementi 找4 ROOM的HDB，预算不超过80万新币，至少90平方米，想看附近地铁站和公园。`

真实模型负责把文字转成经过校验的条件；数据库执行带参数的 SQL；程序检查条件并对当前批次评分。数字表单不需要调用模型。不要把 HDB 4 ROOM 理解为四间卧室，数据没有卧室数量。

**Filters & commute** 可展开预算、面积、地区、HDB类型、街道和通勤。只有本次手动修改的字段覆盖文字要求；此前偏好由会话记住。继续输入“把预算提高到85万”可以更新需求。**New search** 开始一个新的空白会话，不再沿用原来的收藏、拒绝和模拟事件；旧记录不会立即从服务器删除。

## 推荐和反馈

- **Shortlist**：本批次最多先选三套；**Matches**：当前数据库批次。总匹配数与已评分的批次数量分开显示，不声称所有匹配记录都经过全局最优排序。
- **Why this home**：展开参考日期、预算余量、面积及评分说明。
- **Not for me**：选择原因，排除这个分组并重新选择推荐；后续搜索仍记住拒绝。原因是审计记录，不会悄悄改变预算或面积。
- **Show alternatives**：换一组符合条件、未拒绝的候选；当前批次没有其他房屋时继续读取下一批。
- 心形图标保存房屋。收藏保存在服务器会话里，同一浏览器刷新后仍在。`Saved` 表格比较价格、面积和已查到的路线。
- **Approve shortlist**：记录人工确认。不会联系卖家、发送消息、预约或付款。

## 地图与通勤

点击 **Explore home → Map & everyday journeys**。

1. **Show home & nearby places**：OneMap 查询准确楼栋坐标；OpenStreetMap / Overpass 获取周围 1 公里设施。
2. 可选 MRT、Bus stops、Parks、Schools、Food、Shops、Healthcare，点击 **Update places** 更新地图标记。列表中的米数是直线距离，不是步行时间；地图资料可能不完整。
3. 输入新加坡公开目的地/建筑/地铁站/邮编，选择 Walking 或 Driving，点击 **Calculate route**。地图画出真实路网路线，显示预计分钟和公里数。核对显示的目的地名称。
4. 这些时间没有实时交通、室内步行或公共交通班次。MRT / bus 使用 **Google Maps** 外部路线链接；应用不会把步行或直线公式当作公交时间。
5. 在主搜索设置了通勤目的地后，**Check travel times** 检查短名单及少量备选（通常最多6套，手工扩展短名单最多12套），据结果更新推荐。若设了硬性分钟上限，未查到路线或超时的房屋不能被批准。
6. 外部地图服务失败会明确显示未核实，可重试或打开外部地图。系统不生成虚假坐标或分钟数。只有主动查询会调用地图；不会批量为全部数据地理编码。

## 数据变化与执行记录

`How your shortlist was built` 展示工具执行摘要和证据，可继续展开每步参数；它不是模型的私密推理。

房屋详情的 **Demo: test a change in availability or price** 可展开并模拟下架/涨价。事件只作用于当前会话，重新检查预算和反馈并重排；此前的批准会撤销。这是演示事件，**不是检测到真实房源下架**。

`About → Recheck source data` 检查数据库快照。页面可见时也每分钟检查源版本；发现导入的新版本就重新决策。没有外部在售房源轮询或后台定时采集。

## 数据说明

228,225 条 Kaggle HDB历史成交记录（2017-01至2026-04），原始归档已包含在私有仓库 `data/hdb/`，本地运行 `npm run data:hdb` 自动生成数据库，Docker自动完成导入。

价格是历史参考；房屋和可售状态是模拟；地图坐标、周边设施与路网路线来自独立的地图服务。数据许可原标注 `Unknown`，项目不声称获得了额外的公开分发许可。
